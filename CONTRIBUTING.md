# Contributing

Thanks for contributing to **pocket-agent-desktop-app**.

Repository scaffolding was bootstrapped from [@open-templates](https://github.com/open-templates) GitHub templates.

## Setup

```bash
git clone https://github.com/pocket-agent/pocket-agent-desktop-app.git
cd pocket-agent-desktop-app
npm install
```

Requires Rust (`cargo`) and sibling repos — see [../scripts/setup-local.sh](../scripts/setup-local.sh).

## Pull requests

1. Branch from `main`.
2. Keep changes focused; update [CHANGELOG.md](CHANGELOG.md) for user-visible changes.
